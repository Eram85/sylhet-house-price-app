# Sylhet Real Estate Price Predictor
### BSc Thesis Project — Machine Learning-Based House Price Estimation for Sylhet, Bangladesh

---

## Overview

This project builds and compares seven supervised machine learning models to predict residential property prices in Sylhet, Bangladesh. A Streamlit web application allows users to input property details and receive an instant price estimate with a confidence range.

**Models compared:** Linear Regression, Ridge Regression, Decision Tree, Random Forest, Gradient Boosting, XGBoost, SVR

## Dataset

- **Size:** ~299 property listings from Sylhet City Corporation area
- **Sources:** Bikroy.com, bdhousing.com, Facebook Marketplace, and self-collected field data
- **Features:** Property type, location (21 neighbourhoods), size (sqft), bedrooms, bathrooms, floor number, floor level, balcony, parking, lift, CCTV, generator
- **Target:** Selling price (BDT)

## How to Run

### Step 1 — Exploratory Data Analysis
```bash
python eda.py
```
Generates all EDA charts: price distributions, location analysis, amenity impact, correlation heatmap, and data source breakdown.

### Step 2 — Train Models
```bash
python model.py
```
This will:
- Clean and preprocess the dataset
- Split data into train (60%) / validation (20%) / test (20%)
- Train and tune all seven models using `RandomizedSearchCV`
- Print the model comparison table
- Save the best model artefacts as `.pkl` files

### Step 3 — Run the Web App
```bash
streamlit run app.py
```
Opens the price estimator in your browser at `http://localhost:8501`.

> **Important:** Run `model.py` before `app.py` to generate the required `.pkl` files.

## Methodology

### Train / Validation / Test Split
Data is split into three non-overlapping sets:
- **60% Train** — used to fit each model
- **20% Validation** (combined with train for cross-validation during hyperparameter search)
- **20% Test** — held out entirely; only used for final reported metrics

This design avoids data leakage: cross-validation folds are drawn only from the train+validation portion.

### Target Transformation
The selling price is log-transformed (`y = log(price)`) before training. All metrics (R², MAE, RMSE) are computed in the original BDT scale after applying `exp()` to predictions.

### Hyperparameter Tuning
All models (including SVR) use `RandomizedSearchCV` with 5-fold cross-validation. Ridge uses `RidgeCV` for alpha selection.

### Confidence Interval
The Streamlit app displays a ±1 RMSE interval around the point estimate, providing users with an honest range rather than a false single-value precision.

## Limitations

- Dataset size (~299 entries) is small for generalisation; additional data collection is recommended.
- Property prices are self-reported or scraped from listings and may not reflect final transaction prices.
- The model covers Sylhet City Corporation area only and does not generalise to other cities.
